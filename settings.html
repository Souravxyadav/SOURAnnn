How to Host ScholarLedger on InfinityFree

Step-by-step checklist to deploy HTML, CSS, JavaScript files and connect to Supabase.

Free Web Hosting
1
Create Account & Domain on InfinityFree

Sign up at InfinityFree.com. Create a new Free Hosting account and choose a free subdomain (e.g. myportal.infinityfreeapp.com) or custom domain.

2
Open Control Panel & File Manager

In your InfinityFree client area, open the Control Panel (cPanel) and click on Online File Manager (or connect with FileZilla FTP using your FTP credentials).

3
Upload Project Files to htdocs/

Navigate inside the htdocs/ folder. Delete any default placeholder files (e.g. index2.html). Upload all ScholarLedger files & folders: index.html, commissions.html, applications.html, student-portal.html, js/, css/, and .htaccess.

4
Configure Supabase API Keys

Ensure js/config.js has your valid Supabase Project URL & Anon Key so client browsers can communicate directly with your database.

5
Execute SQL Schema in Supabase

Go to your Supabase Dashboard → SQL Editor → Click + New Query → Paste the Complete SQL Schema from the tab above → Click Run.

6
Test Live & Enable Free SSL

In InfinityFree client area, go to Free SSL Certificates to get a free Let's Encrypt certificate. Open your domain in browser to verify student registration, login, and admin panel!
